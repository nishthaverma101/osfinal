About CareQueue

An Operating System-based Hospital Management System

Project Overview

CareQueue is a comprehensive hospital management system built using operating system concepts and algorithms. This system implements various OS algorithms to efficiently manage patient queues, resource allocation, and scheduling in a healthcare environment.

Operating System Algorithms Implemented:
  • Priority Scheduling: Patient queue management based on medical urgency
  • FCFS (First Come First Served): Fair scheduling for non-urgent patients
  • Resource Allocation: Optimal doctor and room assignment
  • Process Management: Patient workflow and status tracking
  • Memory Management: Efficient data storage and retrieval
  • IPC (Inter-Process Communication): Real-time lab report notifications
  • Deadlock Prevention: Avoiding resource conflicts in scheduling
Additional OS Concepts in Practice:
  • File Locking & Synchronization: Cross-process locks in lock_utils.py guard CSV writes and prevent race conditions.
  • Named Pipes & Socket IPC: ipc_bus.py switches between Windows named pipes and TCP sockets for real-time lab alerts.
  • Multithreaded Event Dispatch: Background daemon threads manage IPC subscribers and retries for resilient delivery.
  • Concurrency Control: Thread-safe critical sections (e.g., threading.RLock) coordinate queue updates and notifications.
